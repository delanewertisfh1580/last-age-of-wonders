## 5. Что разблокирует M34

Завершает первую сборку. Дальше: полировка, баланс, мобильный UX, публичный билд (вне scope 039).

## 6. Риски и заметки

- Швы — главный риск: расхождение имён событий между дизайнами ловится только тестом.
- Без эталонных хешей регрессии детерминизма незаметны.
- Визуальный слой не должен блокировать headless-прогон.
